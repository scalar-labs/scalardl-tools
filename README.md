# ScalarDL Tools

This repository holds the tools that support operating a [ScalarDL](https://scalardl.scalar-labs.com/docs/latest/) deployment.

## ScalarDL Cleanup Tool

ScalarDL Cleanup Tool removes the residual transaction state—Coordinator state records and request proofs—that a deployment accumulated while it was running.

For details, see [`scalardl-cleanup/README.md`](scalardl-cleanup/README.md).
